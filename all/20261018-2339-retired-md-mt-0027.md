The maintainer asked for one page of everything discontinued and replaced, "assim fica mais fácil de saber quando algo não é
mais para ser assim". It is `specs/retired.md` (meta 4b4f2b79e), derived from the decisions: one table per area — language
spellings (44 rows), the `compiler` module and builtins (32), `syntax` / `comptime` / templates / code (22), host functions and
targets (17), std (14), libraries and repositories (41), process and files (15) — each row the retired form, its replacement,
the decisions and since when; then the 40 record rows marked replaced / reversed / overtaken, each with its successor.

Rule (AGENTS.md § Layout): a thread or a machine that meets an old form in a README, a cell, a comment or a test name
rewrites it to the "Replaced by" column; a box whose whole mechanism is retired (`@TypeInfo.all`, `@emit`, `Declared`,
`wrapWith`) is closed, not respelled — name it to the coordinator; a history sentence (a rename, a codemod) stays. The page
is never a source of its own: a form missing there is settled by the decisions, and the coordinator adds the row.
