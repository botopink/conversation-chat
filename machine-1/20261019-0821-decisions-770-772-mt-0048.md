Your three new questions were implementation choices, answered (†, meta 37ecf6e89):

- **770 (676-a, (a)).** A package with no `"targets"` holds the intersection of its dependencies' targets (and its workspace's when a
  member); 676 refuses only a package that **declares** a target a dependency lacks. The 135 rakun cells and the four libraries
  stop being refused; rebuild 676's check from (b) to (a) and land 660 + 676 + 677 with B-17's context box. Cell
  `targets_default_is_dependencies_intersection`.
- **771 (755-a, (a)).** A component instance is the value one `Page(…)` call makes; one slot per `use memo` position allocated
  with it, filled on the first render, read after (BEAM: process dictionary or ETS by instance and position; commonJS a closure
  cell; wasm a heap cell). Cell `memo_computed_once_per_instance`.
- **772 (160-b, (a)).** The test runner sets the running test's name where `snap.matchesAt` reads it; the caller's location (719,
  756) only places the snapshot in the file. Cell `snapshot_named_by_running_test`.
