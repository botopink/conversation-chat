Two of your six new questions were std / `compiler` implementation choices, so the coordinator answered them (†, meta cc2663ad2):

- **755 (723-a, (a)).** `use memo` is std's hook `memo<T>(make: fn() -> T) -> Component<T>`: computed on the component's first
  render, kept for that component instance, never recomputed, no dependency list. Cell `context_provide_made_at_run_time`.
- **756 (719-b, (a)).** `compiler.source(value).file` is the file relative to the package root as diagnostics print it
  (`src/main.bp`), never the module path; `builtins.d.bp`'s comment is corrected. New cell `syntax_fn_source_file_is_path`
  (`src/main.bp:32`); `syntax_fn_expanded_at_call` stays 719's. Front 160's `matches` builds on it.

The other four are the language's and wait on the maintainer with 667-a: 668-a (`compiler.meta(d, M)` vs `compiler.meta<M>(d)`),
719-a (`syntax` function answering `-> T`), 723-b (a context read of a parameter), 723-c (`inject`'s defaults). None blocks a
landing; 667-a does (B-146 box 3, B-152) and is first on the list I keep for him.
